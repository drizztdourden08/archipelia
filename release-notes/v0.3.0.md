# Archipelia v0.3.0

Players can now join a session straight from their own client, with the host approving each one, and the Sessions, Games and lobby screens have been rebuilt around that. You can host on your computer, on the local network or on an Archipelia lobby server, and the run header shows how players reach your room.

## New

- A session can turn on direct connections, so players join from their own client through a lobby instead of sending you a player file.
- Each join request waits for the host to approve it, and the host sees the options the player chose before and after approving.
- Show on the network lists your lobby for other people on the local network, and the Joining section of the session has the toggle for it.
- New sessions on this computer or the local network start with direct connections, host approval and Show on the network on.
- The lobby and the run headers show the network facts: the address, host and port players use to reach the room.
- Archipelia lobby servers can run on their own machine, with the Archipelia server manager and the LAN list added to the app.
- The Network widget shows the lobby state while a session is open, and a new default layout groups the widgets in tabs.
- Verified clients are checked against the client registry, and the Games page marks them with a Verified tag.
- Relic of the Past and Ship of Harkinian are listed as verified clients that join a session directly.
- Games now come in Built-in, Archipelia ready and Archipelago index categories, and Archipelia ready worlds are found by their GitHub topic.
- Worlds without a stable release use their newest pre-release and show a Pre-release tag.
- Games that join directly carry a Joins directly tag, and the Games page has a filter for them.
- The Console has a command picker with all 20 Archipelago server commands, each with a slot for every parameter.
- The spoiler widget is now a searchable tracker built from the spoiler log.
- Worlds that are not on PyPI have a guided install, which can use a ready-made wheel from a GitHub release or build the package from source.

## Changes

- Sessions is now its own screen after Home, rebuilt as a compact list with an editor beside it, and Games and Presets sit under Library.
- Hosting and joining moved into Sessions, and the Lobbies page is gone.
- A session slot is either direct, which a player fills from their own client, or set, which you fill with a game and options.
- The session lobby is a framed stage with a seat grid, and a seat has six states with a Set slot dialog in place of the inline editor.
- A joined player card shows a locked Direct type, and you can view the player or delete it.
- Held seats stay reserved for their player, and a join request can name the seat it wants.
- The Players list shows the players you added and the clients that connected together.
- Run asks first when approved seats would not play.
- The History screen replaces the Runs card and Old runs, and shows each slot's final status, checks and goal time with a summary line for the run.
- The Get the package flow is rebuilt as a wizard.
- The Games page is one screen with tabs, a details dialog, a version picker for releases and the release version on every card.
- The session stage shows the generation job as steps.
- Lobby codes are selectable text.

## View

- The game options panel shows any game's options in tabs with Basic and Advanced rows, and the preset editor uses it.
- Long option descriptions fold into a help hint, and save problems list jump links.
- Log views put the filters on the left at small sizes.
- The Console item and location slots search the chosen player's game names, and keep free text.

## Settings

- The Check at start setting controls whether the app looks for a newer engine when it opens.
- The Engine page lets you keep several Archipelago versions side by side, and each session keeps the engine it was made with.

## Around the app

- The welcome tour is rebuilt with click-driven steps and starts from a Take the tour menu entry.
- Data moved into the App group of the menu, ordered by use.
- Open files in History opens the output of a run.
- The app asks before it installs Python packages that a community world needs.

## Platforms

- The Archipelia server runs on Linux in a container, and on Linux it generates unlisted worlds inside a bubblewrap sandbox.

## Under the hood

- The server core, the lobby protocol and the client kit are separate packages, and the lobby protocol and client kit are published for others to use.
- The client kit reads an archipelia.json release manifest, and it builds player files with set and list option rows.
- A world can say that its player file comes from its own app, and Archipelia then shows a problem on the session and the options as read only.
- Calls to GitHub have time limits, and the stored index is shown with a notice when GitHub limits the read.

## Fixes

- A saved Show on the network choice is kept when a session is loaded or run.
- Runs a server left open are closed, and the stop reason is recorded.
- The Console scrolls when its widget is small.
- Searching the Games page scrolls to a card that is not drawn yet.
- Cards with more content no longer spill out of their grid rows.
- The room password prompt of one session no longer shows in another session.
